- 2026-11-06 (Pi job #1, M1): rating fit. Plain weighted log-space least squares gave Eno reference MdAPE 10.7 % (fails the < 10 % gate): Eno's control is compound (mid flows sit above a single power law, floods below, a handful of 2–4 cfs gaugings scatter ±50 %). Switched to weighted **Huber** loss in ln Q (scipy least_squares, f_scale 0.1 ≈ 10 % flow error) inside the bounded 1-D search on e. Same Q = a(H−e)^b form; Eno → 8.0 %, all other sites 3.3–4.8 % (each equal or better). e searched in [Hmin − max(5 ft, stage range), Hmin − 0.01 ft].
- 2026-11-06 (Pi job #1, M1): stage shift sign. `stage_shift_ft = Ĥ(Q_meas) − H_meas` (the USGS gage-height shift you add to the stage reading), so it has the same sign as residual_pct: scour → positive in both % and ft. plan §4 writes Δh = H − Ĥ(Q), which would make the ft number carry the opposite sign from the % number for the same event; picked one sign for both so the agents and UI cannot mix them up. Flipping is one line in rating.py if Grace prefers the plan's literal form.
- 2026-11-06 (Pi job #1, M1): segmentation **penalty = 50**. Series = non-excluded measurements from the reference start onward (older history is a different channel and only adds noise). PELT runs on ln(Q/Q̂) standardized by 1.4826×MAD of the reference residuals, so the penalty is in units of σ² and carries across gauges. Fixed list tried (12 values): 5, 10, 20, 25, 30, 35, 40, 50, 60, 80, 100, 150. Swannanoa shows a post-Helene shift (2025-11, about +12 %) at ≤ 20 and none at ≥ 25; Eno shows none at any value; Newport fires (2024-10, −43 %) at every value. So the working window is 25–150 and **all three conditions hold, no compromise needed**. Picked 50: 2× above the lower edge, 3× below the upper. Shift size = median residual after − median before (a step, in % flow and ft); confidence = 1 − Mann–Whitney p between the two segments.
